# 训练数据交付格式说明

本文档用于告知数据提供方：如果不使用系统自动切分和 ASR，而是自行提供切分音频和文本标注，需要按下面格式交付。

## 交付内容

至少需要提供两部分：

```text
1. 切分后的音频目录
2. 与音频一一对应的 .list 标注文件
```

推荐目录结构：

```text
角色名_训练数据/
├─ wav/
│  ├─ 001.wav
│  ├─ 002.wav
│  └─ 003.wav
└─ labels.list
```

前端训练页选择：

```text
预处理模式：已有标注
切分音频目录：角色名_训练数据/wav
标注文件：角色名_训练数据/labels.list
```

系统会跳过：

```text
音频切分
ASR 自动识别
```

然后直接执行：

```text
文本处理 / BERT 特征
音频特征 / CNHubert
语义 Token 提取
SoVITS / GPT 训练
```

## 音频要求

推荐格式：

```text
wav
单人声
无背景音乐
无明显混响
无多人重叠说话
音量稳定
```

可接受扩展名：

```text
.wav
.mp3
.flac
.m4a
.ogg
.aac
```

但训练数据最推荐交付 `.wav`。

推荐时长：

```text
单条 2-15 秒
更推荐 4-10 秒
```

不建议：

```text
少于 1 秒
超过 20 秒
整段长录音
包含长时间静音
一句话被切断
一个文件里有多个角色说话
```

## .list 标注格式

每一行对应一个音频文件。

格式：

```text
音频文件路径|说话人名|语言|文本内容
```

示例：

```text
D:/data/theresa/wav/001.wav|特蕾西娅|zh|你好，这是一段测试语音。
D:/data/theresa/wav/002.wav|特蕾西娅|zh|今天的工作已经完成了。
D:/data/theresa/wav/003.wav|特蕾西娅|zh|请继续保持通讯畅通。
```

也可以只写文件名，配合“切分音频目录”使用：

```text
001.wav|特蕾西娅|zh|你好，这是一段测试语音。
002.wav|特蕾西娅|zh|今天的工作已经完成了。
003.wav|特蕾西娅|zh|请继续保持通讯畅通。
```

如果 `.list` 里写的是文件名，前端里的“切分音频目录”必须填这些音频所在目录。

## 语言字段

常用值：

```text
zh    中文
yue   粤语
en    英文
ja    日文
ko    韩文
auto  自动
```

中文普通话建议使用：

```text
zh
```

## 文本标注要求

文本必须和音频内容一致。

建议：

```text
保留正常标点
去掉无意义口癖和噪声描述
数字按实际读法写清楚
英文大小写保持可读
不要写舞台说明
不要写括号音效
```

推荐：

```text
001.wav|角色|zh|今天的天气很好，我们一起出去走走吧。
```

不推荐：

```text
001.wav|角色|zh|（笑）今天的天气很好，呃，我们一起出去走走吧。[背景音乐]
```

如果音频里确实读出了“嗯”“啊”等语气词，可以保留；如果只是噪声或非人声，不要写进标注。

## 文件名要求

建议使用简单文件名：

```text
001.wav
002.wav
003.wav
```

或：

```text
role_0001.wav
role_0002.wav
role_0003.wav
```

避免：

```text
文件名包含 | 符号
文件名过长
文件名包含特殊控制字符
同名文件
```

## 交付前自检

交付前请确认：

```text
每个 .list 行都能找到对应音频
音频数量和标注行数一致
音频能正常播放
音频没有大段静音
文本和音频逐句对应
同一个训练包里尽量只有一个说话人
语言字段填写正确
文件编码为 UTF-8
```

## 最小合格示例

目录：

```text
D:/dataset/theresa/
├─ wav/
│  ├─ 001.wav
│  ├─ 002.wav
│  └─ 003.wav
└─ labels.list
```

`labels.list`：

```text
001.wav|特蕾西娅|zh|你好，这是一段测试语音。
002.wav|特蕾西娅|zh|今天的工作已经完成了。
003.wav|特蕾西娅|zh|请继续保持通讯畅通。
```

前端填写：

```text
预处理模式：已有标注
切分音频目录：D:/dataset/theresa/wav
标注文件：D:/dataset/theresa/labels.list
```
