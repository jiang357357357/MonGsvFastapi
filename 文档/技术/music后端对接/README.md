## 当前接入基准

核对日期：2026-10-24。本文档对应当前 FastAPI 网关（默认端口 40302），不使用旧 `7020/api/music` 或 `50007/Core` 路由。

- 训练：优先 [训练工作台说明](./04-训练与模型/README.md)，支持八个模型版本、自动 Batch、最终轮次保存、独立重训与持久化历史。
- 合成：[API 手册](./01-接口协议/01-API完整手册.md) 已列出 `seed/sample_steps/cfg_rate`、V5 默认值、HTTP 表单与 JSON 的区别。
- 流式：[WS 协议](./01-接口协议/02-TTS流式WebSocket设计.md) 按模型区分 `tokens` 与 `segments`；V5 当前为分段返回。
- 示例：[Python](./02-SDK与示例/02-Python-SDK使用指南.md) 和 [curl/JavaScript](./02-SDK与示例/03-curl与HTTP调用示例.md) 使用当前接口；历史 SDK 的兼容边界另有说明。
- 中文训练 ASR：默认 Fun-ASR-Nano-2512 + FSMN VAD，模型固定修订并优先使用本地文件。

对照官方 `main@b4570b8` 时，当前内核基线为 `1b47ca0`，尚未接入官方新增 `gpt_streaming`。已确认但尚未修复的限制包括 V1 文本阶段使用 V2 配置、`if_freeze` 无冻结效果、WS 零值/种子传递及共享模型并发与取消行为。本次只对齐文档，没有将这些能力标为已修复。
