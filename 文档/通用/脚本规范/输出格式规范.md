## 颜色使用规范

### 标准颜色定义
```powershell
# 颜色定义
$ColorGreen = "Green"      # 成功、完成
$ColorYellow = "Yellow"    # 警告、提示
$ColorRed = "Red"          # 错误、失败
$ColorCyan = "Cyan"        # 标题、信息
$ColorMagenta = "Magenta"  # 步骤标题
$ColorGray = "Gray"        # 次要信息
$ColorWhite = "White"      # 重要数据
```

### 颜色使用场景

| 颜色 | 使用场景 | 示例 |
|------|----------|------|
| **Green** | 成功状态、完成操作 | `[✓] 操作成功`, `[SERVER_STATUS:STARTED]` |
| **Yellow** | 警告信息、提示状态 | `[!] 警告信息`, `[SERVER_STATUS:ALREADY_RUNNING]` |
| **Red** | 错误信息、失败状态 | `[✗] 操作失败`, `[SERVER_STATUS:FAILED]` |
| **Cyan** | 标题、信息标识符 | 脚本标题、`[PROCESS_NAME:xxx]` |
| **Magenta** | 步骤标题 | `[1/5] 检查环境...` |
| **Gray** | 次要信息、帮助文本 | 详细说明、按键提示 |
| **White** | 重要数据 | 进程ID、端口号、路径 |

### 表格数据对齐
```powershell
# 计算显示宽度（处理中英文混合）
function Get-DisplayWidth($text) {
    $width = 0
    for ($i = 0; $i -lt $text.Length; $i++) {
        $char = $text[$i]
        if ([int][char]$char -gt 127) {
            $width += 2  # 中文字符
        } else {
            $width += 1  # 英文字符
        }
    }
    return $width
}

function Pad-ToDisplayWidth($text, $targetWidth) {
    $currentWidth = Get-DisplayWidth $text
    $paddingNeeded = $targetWidth - $currentWidth
    if ($paddingNeeded -gt 0) {
        return $text + (" " * $paddingNeeded)
    }
    return $text
}

# 使用示例
$serviceName = Pad-ToDisplayWidth "MonHub 消息中转站" 18
Write-Host "│ $serviceName │" -ForegroundColor $ColorWhite
```

## 进度显示格式

### 简单进度条
```powershell
function Show-Progress {
    param(
        [int]$Current,
        [int]$Total,
        [string]$Activity
    )
    
    $Percent = [math]::Round(($Current / $Total) * 100)
    $BarLength = 40
    $FilledLength = [math]::Round(($Current / $Total) * $BarLength)
    
    $Bar = "█" * $FilledLength + "░" * ($BarLength - $FilledLength)
    
    Write-Host "`r$Activity [$Bar] $Percent% ($Current/$Total)" -NoNewline -ForegroundColor $ColorCyan
}

# 使用示例
for ($i = 1; $i -le 100; $i++) {
    Show-Progress -Current $i -Total 100 -Activity "处理中"
    Start-Sleep -Milliseconds 50
}
Write-Host ""  # 换行
```

## 日志输出格式

### 日志级别格式
```powershell
function Write-Log {
    param(
        [string]$Message,
        [ValidateSet("INFO", "SUCCESS", "WARNING", "ERROR")]
        [string]$Level = "INFO"
    )
    
    $Timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    $LogEntry = "[$Timestamp] [$Level] $Message"
    
    # 输出到控制台
    switch ($Level) {
        "INFO"    { Write-Host $LogEntry -ForegroundColor $ColorCyan }
        "SUCCESS" { Write-Host $LogEntry -ForegroundColor $ColorGreen }
        "WARNING" { Write-Host $LogEntry -ForegroundColor $ColorYellow }
        "ERROR"   { Write-Host $LogEntry -ForegroundColor $ColorRed }
    }
    
    # 同时写入日志文件
    $LogEntry | Out-File -FilePath $LogFile -Append -Encoding UTF8
}

# 使用示例
Write-Log "脚本开始执行" "INFO"
Write-Log "配置加载成功" "SUCCESS"
Write-Log "发现潜在问题" "WARNING"
Write-Log "操作执行失败" "ERROR"
```
