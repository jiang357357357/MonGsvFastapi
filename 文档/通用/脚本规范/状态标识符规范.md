## 概述

为了确保脚本间的一致性和自动化工具的正确解析，所有PowerShell脚本必须输出标准化的状态标识符。

## 标识符格式

### 基本格式
```
[标识符类型:状态值]
```

### 输出要求
- 必须使用方括号 `[]` 包围
- 标识符类型和状态值之间使用冒号 `:` 分隔
- 输出时使用适当的颜色（见颜色规范）
- 每个标识符单独一行

---

## 进程标识符

### PROCESS_NAME
**用途**: 标识进程名称
**格式**: `[PROCESS_NAME:进程名称]`
**示例**:
```powershell
Write-Host "[PROCESS_NAME:MonCore-Django]" -ForegroundColor Cyan
Write-Host "[PROCESS_NAME:MonHub-Service]" -ForegroundColor Cyan
Write-Host "[PROCESS_NAME:MonOs-Service]" -ForegroundColor Cyan
```

### PROCESS_PID
**用途**: 标识进程ID
**格式**: `[PROCESS_PID:进程ID]`
**示例**:
```powershell
Write-Host "[PROCESS_PID:12345]" -ForegroundColor Cyan
Write-Host "[PROCESS_PID:12345 67890]" -ForegroundColor Cyan  # 多个PID用空格分隔
```

## 服务状态标识符

### SERVER_STATUS
**用途**: 标识服务运行状态
**适用脚本**: 所有进程管理脚本（start_process.ps1, stop_process.ps1, status_process.ps1）

#### 启动状态
| 状态值 | 含义 | 使用场景 | 颜色 |
|--------|------|----------|------|
| `STARTING` | 正在启动 | start脚本中，服务启动过程中 | Green |
| `STARTED` | 启动成功 | start脚本中，服务成功启动后 | Green |
| `ALREADY_RUNNING` | 已在运行 | start脚本中，发现服务已运行 | Yellow |
| `FAILED` | 启动失败 | start脚本中，启动过程失败 | Red |

#### 运行状态
| 状态值 | 含义 | 使用场景 | 颜色 |
|--------|------|----------|------|
| `RUNNING` | 正在运行 | status脚本中，服务正常运行 | Green |
| `NOT_RUNNING` | 未运行 | status脚本中，服务未运行 | Yellow |

#### 停止状态
| 状态值 | 含义 | 使用场景 | 颜色 |
|--------|------|----------|------|
| `STOPPED` | 停止成功 | stop脚本中，成功停止服务 | Green |
| `NOT_RUNNING` | 未在运行 | stop脚本中，服务本来就未运行 | Yellow |
| `FAILED` | 停止失败 | stop脚本中，停止过程失败 | Red |

#### 示例代码
```powershell
# 启动脚本示例
Write-Host "[SERVER_STATUS:STARTING]" -ForegroundColor Green
# ... 启动逻辑 ...
Write-Host "[SERVER_STATUS:STARTED]" -ForegroundColor Green

# 状态脚本示例
if ($ServiceRunning) {
    Write-Host "[SERVER_STATUS:RUNNING]" -ForegroundColor Green
} else {
    Write-Host "[SERVER_STATUS:NOT_RUNNING]" -ForegroundColor Yellow
}

# 停止脚本示例
if ($StopSuccess) {
    Write-Host "[SERVER_STATUS:STOPPED]" -ForegroundColor Green
} else {
    Write-Host "[SERVER_STATUS:FAILED]" -ForegroundColor Red
}
```

## 端口状态标识符

### PORT_STATUS
**用途**: 标识端口占用状态
**格式**: `[PORT_STATUS:状态值]`

| 状态值 | 含义 | 颜色 |
|--------|------|------|
| `LISTENING` | 端口正在监听 | Green |
| `NOT_LISTENING` | 端口未被占用 | Yellow |
| `ERROR` | 端口检查出错 | Red |

#### 示例代码
```powershell
try {
    $Connections = Get-NetTCPConnection -LocalPort $Port -State Listen -ErrorAction SilentlyContinue
    if ($Connections) {
        Write-Host "[PORT_STATUS:LISTENING]" -ForegroundColor Green
    } else {
        Write-Host "[PORT_STATUS:NOT_LISTENING]" -ForegroundColor Yellow
    }
} catch {
    Write-Host "[PORT_STATUS:ERROR]" -ForegroundColor Red
}
```

## 脚本执行状态标识符

### SCRIPT_STATUS
**用途**: 标识脚本整体执行状态
**格式**: `[SCRIPT_STATUS:状态值]`

| 状态值 | 含义 | 使用场景 | 颜色 |
|--------|------|----------|------|
| `SUCCESS` | 执行成功 | 脚本正常完成所有任务 | Green |
| `FAILED` | 执行失败 | 脚本执行过程中出现错误 | Red |
| `PARTIAL` | 部分成功 | 批量操作中部分成功 | Yellow |

## 统一管理脚本标识符

### 批量操作状态
用于 start_all.ps1, stop_all.ps1, status_all.ps1 等统一管理脚本

#### 服务计数格式
```powershell
# 成功启动的服务数量
Write-Host "运行中服务: $runningCount / $totalCount" -ForegroundColor Cyan

# 汇总状态框
if ($runningCount -eq $totalCount) {
    Write-Host "╔════════════════════════════════════════════════╗" -ForegroundColor Green
    Write-Host "║  [✓] 所有服务运行正常！                        ║" -ForegroundColor Green
    Write-Host "╚════════════════════════════════════════════════╝" -ForegroundColor Green
}
```

## 颜色规范

### 标准颜色定义
```powershell
$ColorGreen = "Green"      # 成功状态
$ColorYellow = "Yellow"    # 警告状态
$ColorRed = "Red"          # 错误状态
$ColorCyan = "Cyan"        # 信息标识符
$ColorMagenta = "Magenta"  # 步骤标题
$ColorGray = "Gray"        # 次要信息
$ColorWhite = "White"      # 重要数据
```

### 状态标识符颜色映射
| 状态类型 | 颜色 | 说明 |
|----------|------|------|
| 成功状态 | Green | STARTED, RUNNING, STOPPED, SUCCESS |
| 警告状态 | Yellow | ALREADY_RUNNING, NOT_RUNNING, PARTIAL |
| 错误状态 | Red | FAILED, ERROR |
| 信息标识符 | Cyan | PROCESS_NAME, PROCESS_PID |

## 解析规范

### 自动化脚本解析
统一管理脚本（如 start_all.ps1）应该使用正则表达式解析状态标识符：

```powershell
# 解析服务状态
if ($outputStr -match '\[SERVER_STATUS:STARTED\]') {
    $result.Status = "Started"
} elseif ($outputStr -match '\[SERVER_STATUS:ALREADY_RUNNING\]') {
    $result.Status = "AlreadyRunning"
} elseif ($outputStr -match '\[SERVER_STATUS:FAILED\]') {
    $result.Status = "Failed"
}

# 解析进程ID
if ($outputStr -match '\[PROCESS_PID:(\d+)\]') {
    $result.PID = [int]$Matches[1]
}
```

## 兼容性说明

### 废弃的标识符
以下标识符已废弃，请迁移到新格式：

| 废弃格式 | 新格式 | 迁移说明 |
|----------|--------|----------|
| `[STOP_STATUS:SUCCESS]` | `[SERVER_STATUS:STOPPED]` | 停止脚本成功 |
| `[STOP_STATUS:FAILED]` | `[SERVER_STATUS:FAILED]` | 停止脚本失败 |
| `[STOP_STATUS:NOT_RUNNING]` | `[SERVER_STATUS:NOT_RUNNING]` | 服务未运行 |

## 测试验证

### 验证方法
1. **单独运行脚本**: 确认输出正确的状态标识符
2. **统一管理脚本**: 确认能正确解析状态
3. **自动化测试**: 编写测试脚本验证解析逻辑

### 测试用例
```powershell
# 测试状态标识符输出
function Test-StatusOutput {
    param([string]$ScriptPath)
    
    $output = & $ScriptPath -NoWait 2>&1 | Out-String
    
    # 检查是否包含必需的标识符
    $hasProcessName = $output -match '\[PROCESS_NAME:.+\]'
    $hasServerStatus = $output -match '\[SERVER_STATUS:.+\]'
    
    Write-Host "脚本: $ScriptPath"
    Write-Host "  PROCESS_NAME: $hasProcessName"
    Write-Host "  SERVER_STATUS: $hasServerStatus"
}
```
