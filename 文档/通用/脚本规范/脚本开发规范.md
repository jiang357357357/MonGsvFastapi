## 概述

MonCore项目使用PowerShell作为主要的脚本语言，用于自动化各种运维和开发任务。本规范定义了脚本开发的标准和最佳实践。

### 设计原则

- **一致性**: 所有脚本遵循统一的结构和风格
- **可读性**: 清晰的注释和输出信息
- **健壮性**: 完善的错误处理和验证
- **可维护性**: 模块化设计，易于扩展
- **用户友好**: 友好的交互和提示信息

## 脚本命名规范

### 命名规则

1. **使用小写字母和下划线**: `start_process.ps1`
2. **动词+名词结构**: `check_env.ps1`, `install_env.ps1`
3. **清晰描述功能**: 名称应明确表达脚本用途
4. **统一后缀**: 所有PowerShell脚本使用`.ps1`后缀

### 常用动词

| 动词 | 含义 | 示例 |

## 脚本结构规范

### 标准脚本模板

```powershell
# ============================================================
# 脚本名称和用途描述
# 功能：详细说明脚本的功能
# 作者：林星晚
# 日期：2026-04-24
# ============================================================

# 参数定义
param(
    [switch]$Force = $false,
    [string]$ConfigPath = ""
)

# 设置错误处理
$ErrorActionPreference = "Stop"

# 设置UTF-8编码
$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 颜色定义
$ColorGreen = "Green"
$ColorYellow = "Yellow"
$ColorRed = "Red"
$ColorCyan = "Cyan"
$ColorMagenta = "Magenta"

# 获取项目根目录
$ScriptDir = Split-Path -Parent $MyInvocation.MyCommand.Path
$ProjectRoot = Split-Path -Parent (Split-Path -Parent $ScriptDir)

# 显示标题
Write-Host "================================================" -ForegroundColor $ColorCyan
Write-Host "脚本标题" -ForegroundColor $ColorCyan
Write-Host "================================================" -ForegroundColor $ColorCyan
Write-Host ""

# 主要逻辑
try {
    # 1. 参数验证
    Write-Host "[1/N] 验证参数..." -ForegroundColor $ColorMagenta
    # 验证逻辑
    
    # 2. 环境检查
    Write-Host "[2/N] 检查环境..." -ForegroundColor $ColorMagenta
    # 检查逻辑
    
    # 3. 执行主要任务
    Write-Host "[3/N] 执行任务..." -ForegroundColor $ColorMagenta
    # 任务逻辑
    
    # 成功提示
    Write-Host ""
    Write-Host "================================================" -ForegroundColor $ColorGreen
    Write-Host "[✓] 任务完成！" -ForegroundColor $ColorGreen
    Write-Host "================================================" -ForegroundColor $ColorGreen
    Write-Host ""
    
} catch {
    # 错误处理
    Write-Host ""
    Write-Host "================================================" -ForegroundColor $ColorRed
    Write-Host "[✗] 任务失败！" -ForegroundColor $ColorRed
    Write-Host "================================================" -ForegroundColor $ColorRed
    Write-Host ""
    Write-Host "错误信息: $_" -ForegroundColor $ColorRed
    exit 1
}

# 等待用户确认（可选）
Write-Host "按任意键退出..." -ForegroundColor Gray
$null = $Host.UI.RawUI.ReadKey("NoEcho,IncludeKeyDown")
```

## 配置文件集成

### 读取.monconfig配置

所有脚本应该从`.monconfig`读取配置，而不是硬编码：

```powershell
# 读取配置文件
$ConfigFile = Join-Path $ProjectRoot ".monconfig"

if (Test-Path $ConfigFile) {
    $ConfigContent = Get-Content $ConfigFile -Raw
    
    # 读取进程名称
    if ($ConfigContent -match '\[process\][\s\S]*?NAME=(.+)') {
        $ProcessName = $Matches[1].Trim()
    }
    
    # 读取服务端口
    if ($ConfigContent -match '\[server\][\s\S]*?PORT=(.+)') {
        $ServerPort = $Matches[1].Trim()
    }
    
    # 读取服务名称
    if ($ConfigContent -match '\[service\][\s\S]*?NAME=(.+)') {
        $ServiceName = $Matches[1].Trim()
    }
}
```

### 配置项映射

| 配置段 | 配置项 | 用途 |
|--------|--------|------|
| `[service]` | `NAME` | 服务名称 |
| `[service]` | `VERSION` | 版本号 |
| `[server]` | `HOST` | 服务器地址 |
| `[server]` | `PORT` | 服务端口 |
| `[process]` | `NAME` | 进程名称 |
| `[log]` | `LEVEL` | 日志级别 |
| `[log]` | `FILE` | 日志文件路径 |

## 错误处理规范

### 错误处理策略

```powershell
# 设置错误处理模式
$ErrorActionPreference = "Stop"  # 遇到错误立即停止

try {
    # 主要逻辑
    
} catch {
    # 错误处理
    Write-Host ""
    Write-Host "================================================" -ForegroundColor $ColorRed
    Write-Host "[✗] 操作失败！" -ForegroundColor $ColorRed
    Write-Host "================================================" -ForegroundColor $ColorRed
    Write-Host ""
    Write-Host "错误信息: $_" -ForegroundColor $ColorRed
    Write-Host "错误位置: $($_.InvocationInfo.ScriptLineNumber)" -ForegroundColor $ColorGray
    Write-Host ""
    
    # 提供解决建议
    Write-Host "可能的解决方案:" -ForegroundColor $ColorYellow
    Write-Host "  1. 检查配置文件是否正确" -ForegroundColor $ColorGray
    Write-Host "  2. 确认权限是否足够" -ForegroundColor $ColorGray
    Write-Host "  3. 查看日志文件获取详细信息" -ForegroundColor $ColorGray
    Write-Host ""
    
    exit 1
}
```

### 条件错误处理

```powershell
# 检查文件是否存在
if (-not (Test-Path $FilePath)) {
    Write-Host "[✗] 文件不存在: $FilePath" -ForegroundColor $ColorRed
    exit 1
}

# 检查命令是否可用
$Command = Get-Command "uv" -ErrorAction SilentlyContinue
if (-not $Command) {
    Write-Host "[✗] 未找到命令: uv" -ForegroundColor $ColorRed
    Write-Host "    请先安装: pip install uv" -ForegroundColor $ColorYellow
    exit 1
}
```

## 日志记录规范

### 日志文件位置

```
Data/Logs/
├── Process/            # 进程管理日志
│   └── moncore_process.log
├── Scripts/            # 脚本执行日志
│   └── script_execution.log
└── Text/               # 应用日志
    └── MonCore/
        └── MonCore.log
```

### 日志记录方法

```powershell
# 创建日志目录
$LogDir = Join-Path $ProjectRoot "Data\Logs\Scripts"
if (-not (Test-Path $LogDir)) {
    New-Item -ItemType Directory -Path $LogDir -Force | Out-Null
}

$LogFile = Join-Path $LogDir "script_name.log"
$Timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"

# 记录日志
function Write-Log {
    param(
        [string]$Message,
        [string]$Level = "INFO"
    )
    
    $LogEntry = "[$Timestamp] [$Level] $Message"
    $LogEntry | Out-File -FilePath $LogFile -Append -Encoding UTF8
    
    # 同时输出到控制台
    switch ($Level) {
        "INFO"    { Write-Host $Message -ForegroundColor $ColorCyan }
        "SUCCESS" { Write-Host $Message -ForegroundColor $ColorGreen }
        "WARNING" { Write-Host $Message -ForegroundColor $ColorYellow }
        "ERROR"   { Write-Host $Message -ForegroundColor $ColorRed }
    }
}

# 使用示例
Write-Log "脚本开始执行" "INFO"
Write-Log "操作成功完成" "SUCCESS"
Write-Log "发现潜在问题" "WARNING"
Write-Log "操作失败" "ERROR"
```

## 参数设计规范

### 参数类型

```powershell
param(
    # 开关参数（布尔值）
    [switch]$Force = $false,
    [switch]$Verbose = $false,
    [switch]$DryRun = $false,
    
    # 字符串参数
    [string]$ConfigPath = "",
    [string]$OutputDir = "",
    
    # 整数参数
    [int]$Timeout = 30,
    [int]$RetryCount = 3,
    
    # 枚举参数
    [ValidateSet("Debug", "Info", "Warning", "Error")]
    [string]$LogLevel = "Info",
    
    # 必需参数
    [Parameter(Mandatory=$true)]
    [string]$RequiredParam
)
```

### 参数验证

```powershell
# 验证文件路径
if ($ConfigPath -and -not (Test-Path $ConfigPath)) {
    Write-Host "[✗] 配置文件不存在: $ConfigPath" -ForegroundColor $ColorRed
    exit 1
}

# 验证数值范围
if ($Timeout -lt 1 -or $Timeout -gt 300) {
    Write-Host "[✗] 超时时间必须在1-300秒之间" -ForegroundColor $ColorRed
    exit 1
}

# 验证目录权限
try {
    $TestFile = Join-Path $OutputDir "test.tmp"
    New-Item -ItemType File -Path $TestFile -Force | Out-Null
    Remove-Item $TestFile -Force
} catch {
    Write-Host "[✗] 输出目录无写入权限: $OutputDir" -ForegroundColor $ColorRed
    exit 1
}
```

### 参数帮助信息

```powershell
<#
```
