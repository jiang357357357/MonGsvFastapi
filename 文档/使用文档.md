# MonGPT 后端 API 对接文档

本文档提供 MonGPT 后端 API 的接口定义、请求参数与响应结构说明。

## 1. 基础配置

- **Base URL**: `http://localhost:50007/Core`
- **CORS**: 已开启，允许所有来源 (`*`)。
- **数据格式**: JSON
- **认证**: 目前无需认证。

> **注意**: 所有 API 路径均需加上 `/Core` 前缀。

## 2. 接口详解

### 2.1 语音合成 (TTS)

#### 2.1.1 获取服务状态
查询推理服务运行状态及当前加载的模型。

- **URL**: `/api/inference/status`
- **Method**: `GET`
- **Response**:
  ```json
  {
    "is_running": true,
    "current_model": {
        "gpt_path": "...",
        "sovits_path": "..."
    }
  }
  ```

#### 2.1.2 加载/切换模型
启动推理服务或切换使用的模型。

- **URL**: `/api/inference/tts/change`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "version": "v2",
    "character": "GptSovits",
    "gpu_number": "0-0",
    "batched_infer_enabled": false
  }
  ```
- **说明**: 
  - `character`: 模型名称。
  - `version`: 模型版本（通常为 "v2"）。

#### 2.1.3 合成语音
将文本转换为语音音频流。

- **URL**: `/api/inference/tts/synthesize`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "text": "你好，这是一段测试语音。",
    "text_language": "中文",
    "character": "GptSovits",
    "emotion": "default",
    "version": "v2",
    "prompt_text": "这里可以填写你的参考文本（可选）",
    "speed": 1.0,
    "top_k": 5,
    "top_p": 1.0,
    "temperature": 1.0
  }
  ```
- **说明**:
  - `prompt_text` 可选；提供后将覆盖情感系统中的参考文本。
  - 参考文本语言由情感系统绑定；若未绑定则回落为 `中文`。
- **Response**: `audio/wav` 二进制流。

### 2.2 模型训练流程

#### 2.2.1 实时日志流 (SSE)
训练过程中的日志通过 SSE 推送。

- **URL**: `/api/train/log/stream`
- **Method**: `GET`
- **Response Type**: `text/event-stream`
- **Data Format**: 纯文本日志行。

#### 2.2.2 启动 SoVITS 训练
- **URL**: `/api/train/sovits`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "exp_name": "model_name",
    "total_epoch": 8,
    "batch_size": 4,
    "gpu_numbers": "0",
    "save_every_epoch": 4
  }
  ```

#### 2.2.3 启动 GPT 训练
- **URL**: `/api/train/gpt`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "exp_name": "model_name",
    "total_epoch": 15,
    "batch_size": 4,
    "gpu_numbers": "0"
  }
  ```

---

### 2.3 数据预处理

#### 2.3.1 音频切分
- **URL**: `/api/preprocess/slice`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "inp": "C:\\path\\to\\input.wav",
    "opt_root": "C:\\path\\to\\output_dir",
    "threshold": -34,
    "min_length": 4000
  }
  ```

#### 2.3.2 语音降噪
- **URL**: `/api/preprocess/denoise`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "inp_dir": "C:\\path\\to\\sliced_dir",
    "opt_dir": "C:\\path\\to\\denoised_dir"
  }
  ```

#### 2.3.3 ASR (自动语音识别)
- **URL**: `/api/preprocess/asr`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "inp_dir": "C:\\path\\to\\denoised_dir",
    "opt_dir": "C:\\path\\to\\output",
    "model_size": "large"
  }
  ```

#### 2.3.4 数据集格式化 (SSE)
步骤 1a: 文本分词与特征提取。

- **URL**: `/api/train/dataset/prepare/step1a/stream`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "inp_text": "C:\\path\\to\\text",
    "inp_wav_dir": "C:\\path\\to\\wav",
    "exp_name": "model_name",
    "gpu_numbers": "0-0",
    "bert_pretrained_dir": "..."
  }
  ```
- **Response Type**: `text/event-stream`

## 3. 路由速查表

| 模块 | URL 前缀 | 常用功能 |
| :--- | :--- | :--- |
| **信息查询** | `/api/info` | 获取系统信息、版本、GPU列表 |
| **预处理** | `/api/preprocess` | 切分、降噪、ASR |
| **数据集** | `/api/train/dataset/prepare` | 文本分词、BERT特征提取 (Step 1-2) |
| **训练** | `/api/train` | SoVITS训练、GPT训练、日志流 |
| **推理** | `/api/inference` | TTS合成、加载模型、服务状态 |
| **模型管理** | `/api/models` | 列出已训练模型、删除模型 |
| **情感管理** | `/api/emotions` | 获取参考音频预设 (Emotions) |

### 示例 URL
- 获取 GPU 信息: `http://localhost:50007/Core/api/info/gpus`
- 列出模型: `http://localhost:50007/Core/api/models/list?version=v2`
